# 📖 Présentation

Ce projet est une API REST destinée à une plateforme e-commerce. Elle fournit les services nécessaires à la gestion des utilisateurs, des produits, des catégories, des commandes et de l'authentification.

L'objectif est de proposer une architecture backend robuste, évolutive et facilement maintenable en utilisant les bonnes pratiques de développement avec NestJS.

# 🚀 Installation

### Cloner le projet

```bash
git clone https://github.com/didier-lobognon/PROJET_Backend_Ecommerce.git
```

### Installer les dépendances

```bash
npm install
```

### Configurer les variables d'environnement

```env
DATABASE_URL=
JWT_SECRET=
PORT=
```

### Générer Prisma

```bash
npx prisma generate
```

### Exécuter les migrations

```bash
npx prisma migrate dev
```

### Lancer le serveur

```bash
npm run start:dev
```
